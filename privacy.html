Política de privacidad

METIB Personal Drive Sync es una aplicación de uso personal para consultar y descargar archivos de Google Drive autorizados por el titular de la cuenta.

Permiso y uso de datos

La aplicación solicita https://www.googleapis.com/auth/drive.readonly. Este permiso puede permitir leer archivos de todo el Drive de la cuenta autorizada. Los datos se utilizan para la consulta y descarga autorizadas; la aplicación no sube, modifica ni elimina archivos de Drive.

Almacenamiento y comunicación

Los datos y credenciales de autorización se gestionan en el entorno del titular. La aplicación no dispone de un servidor propio para recibir archivos ni vende los datos de Drive. GitHub Pages aloja esta página pública y puede procesar solicitudes web conforme a sus políticas.

Revocación y contacto

El titular puede revocar el permiso desde las conexiones de terceros de su cuenta de Google. Para consultas sobre esta política, puede utilizar el correo de asistencia indicado en la pantalla de consentimiento de Google.
